# Smart Parking Management System

## Description
This project is a Smart Parking Management System developed in Java using Object-Oriented Programming concepts and MySQL database connectivity.

The system allows users to:
- Park Cars
- Park Bikes
- Calculate Parking Fees
- Store Records in Database
- View Parking Records

---

## OOP Concepts Used
- Classes & Objects
- Inheritance
- Polymorphism
- Abstraction
- Encapsulation
- Interfaces
- Exception Handling

---

## Technologies Used
- Java
- MySQL
- JDBC

## How to Run
1. Import project in Eclipse/IntelliJ

3. Run parking.sql
4. Add MySQL JDBC Connector
5. Run Main.java
